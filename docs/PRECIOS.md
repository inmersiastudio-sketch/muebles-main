# Precios y posicionamiento

## Propuesta de planes

Asumo precios mensuales en USD.

| Plan | Precio | ARS aprox. | Enfoque |
| --- | ---: | ---: | --- |
| Basic | `USD 25` | `ARS 37.800` | Entrada para mueblerias chicas. |
| Premium | `USD 40` | `ARS 60.500` | Plan principal de trabajo. |
| Enterprise | `USD 100` | `ARS 151.300` | Operacion avanzada o multi-sucursal. |

Conversion aproximada usando el tipo de cambio oficial vendedor del BCRA
informado en la ultima serie disponible: `ARS 1.513,22 / USD`.

## Comparacion con el mercado

### Wix

- Wix Studio publica planes aproximados de `USD 19`, `USD 27`, `USD 34` y
  `USD 159` mensuales en facturacion anual.
- Wix Premium para sitios editor clasico muestra valores cercanos a
  `USD 17,77`, `USD 29,77`, `USD 39,77` y `USD 159,77`.
- Wix es una referencia de constructor web generalista y agencia, no de una
  plataforma vertical para muebles con AR.

### Shopify

- Shopify publica `Basic` en `USD 29`, `Grow` en `USD 79`, `Advanced` en
  `USD 299` y `Plus` desde `USD 2.300` mensuales.
- Shopify si soporta modelos 3D y AR en producto, pero como parte de un stack
  de e-commerce general. No esta enfocado en el flujo especifico de muebles
  con modelado, embalaje y validacion dimensional.

### Tiendanube

- Tiendanube Argentina publica `Inicial` gratis, `Esencial` en `ARS 26.999`,
  `Impulso` en `ARS 78.999`, `Escala` en `ARS 234.999` y `Evolucion` a medida.
- En Argentina es una referencia mas directa para precios locales de SaaS de
  venta online.

## Opinion tecnica y comercial

Mi opinion es que `USD 25 / 40 / 100` es defendible, pero no como una
plataforma web generica. Solo funciona si el valor diferencial real es:

- catalogo de muebleria,
- consulta comercial,
- 3D/AR visible en la ficha,
- y una operacion simple para publicar modelos.

Lo que veo:

- `USD 25` para Basic esta bien si el plan es una entrada limitada, con pocos
  modelos activos y pocos creditos de generacion.
- `USD 40` para Premium me parece el plan mas sano de la grilla. Es el precio
  que mejor encaja con un producto nicho.
- `USD 100` para Enterprise me parece bajo si incluye soporte humano, mas de
  una tienda, onboarding o personalizacion seria. Para eso lo subiria o lo
  dejaria como `desde USD 100` con add-ons.

## Veredicto

- Para competir contra Wix o Shopify como creador web general, estos precios
  no alcanzan para ganar por volumen ni por amplitud de funciones.
- Para competir como plataforma vertical para mueblerias con 3D/AR, el
  esquema si tiene sentido.
- La ventaja no esta en ser mas barato que Wix o Shopify; esta en resolver un
  problema especifico que ellos resuelven solo de forma parcial.

## Recomendacion

- Mantener `Basic` como plan de entrada con cupo chico de modelos AR activos.
- Usar `Premium` como plan principal y el mas visible.
- Dejar `Enterprise` con precio variable o con servicios extra facturados por
  separado.
- No vender `AR` como gratis si consume generacion, almacenamiento y soporte.
